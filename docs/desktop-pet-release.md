# DesktopPet 0.1.5

桌宠插件独立发布，适用于 **StarPie v1.8.0-beta.7 或更新的 SDK 1.11 兼容宿主**。插件 ID 保持 `io.github.softblack42.desktoppet`，已安装同 ID 的用户保留现有设置、形象库和素材，不需要身份迁移。

## 安装

1. 下载 `StarPie.Plugin.DesktopPet-0.1.5.zip`，按 `SHA256SUMS.txt` 核验后解压到独立目录。
2. 在 StarPie「插件与扩展」选择手动安装 DLL，选择解压目录中的 `StarPie.Plugin.DesktopPet.dll`；保留同目录的 `plugin.json`。
3. 确认 Ui 与 Wheel 权限，按自己的需要启用桌宠；将「桌宠」动作绑定到轮盘或手势后显示。

`.spkg` 与 `.zip` 是完全相同的三文件容器，前者供插件包工具使用，后者便于系统直接解压。包内只有 DLL、plugin.json 和 module.manifest.json，不包含 SDK、主程序、用户数据或形象素材。签名包可通过随附的 `.sigstore.json` 验证。

## 功能

- 点击桌宠呼出宿主轮盘，跟随选区方向切换姿势；拖动或长按拖动移动位置。
- 「管理桌宠」导入本地形象、切换、排序及软删除，使用用户自己的独立素材目录。
- 宿主声明式设置页提供尺寸、拖动方式、长按时长及动画分区；支持速度、拖动姿势与指向姿势。
- 兼容旧显示/隐藏动作引用；插件初始化只注册功能，不自动显示窗口或重新启用禁用状态。

保留现有 ID 的此版本不加入 beta.7 的 `starpie.*` 官方市场目录，因此安装和更新使用本发布页，不会改变其他官方模块历史。所有生产源文件已对照验收 DLL 的 embedded PDB 校验；构建、隔离加载/卸载、无真实动作的 headless 回归及三文件包边界检查通过。
