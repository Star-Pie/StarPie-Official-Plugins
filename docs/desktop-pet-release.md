# DesktopPet 0.1.6 正式版

桌宠现通过 StarPie 官方插件市场分发，适用于 **StarPie v1.8.0-beta.7 或更新的 SDK 1.11 兼容宿主**。市场 ID 为 `starpie.plugin.desktoppet`，保留原作者 SoftBlack42 与 MIT 许可。

## 安装与使用

在「插件与扩展」打开官方市场，刷新目录，选择「桌宠」安装，确认 Ui 与 Wheel 权限后按需启用。将「桌宠」动作绑定到轮盘或手势；通过「管理桌宠」导入自己的本地形象素材。包只包含 DLL 与两份元数据，不包含 SDK、主程序、形象素材或用户数据。

- 点击桌宠呼出宿主轮盘，跟随选区方向切换姿势；拖动或长按拖动移动位置。
- 「管理桌宠」支持导入、切换、排序及软删除。
- 设置页提供尺寸、拖动方式、长按时长、动画速度及拖动/指向姿势配置。
- 初始化只注册功能，不自动显示窗口，不重新启用已禁用插件。

## 从独立版切换

独立版 0.1.5 的 ID 为 `io.github.softblack42.desktoppet`。beta.7 官方市场要求 `starpie.*` 保留 ID，因此本版使用新的官方身份，不能作为原 ID 的原位升级；原发布页、设置、形象库和素材均保留。

1. 先在插件页停用旧 ID 的桌宠，再从市场安装本版，避免同时显示两个桌宠。
2. 在本版「管理桌宠」重新导入原来使用的素材目录，并按需设置尺寸、位置及动画选项。此过程不删除原目录或旧形象库。
3. 将需要切换的轮盘/手势动作重新选择为市场版「桌宠」。旧动作绑定不会被静默改写；保留旧版可供回退。

正式版通过现有官方模块工作流构建、回归测试、校验并签名，市场使用发布目录内的 SHA-256 验证下载。此版本仅调整官方身份、版本与分发元数据，桌宠生产交互逻辑与已验收的 0.1.5 一致。
